# Windows 首次测试清单

## 准备
- 从 GitHub → Actions → 最新一次成功构建 → Artifacts 下载 `facemask-windows-x64`，解压到一个**带中文**的路径（例如 `D:\测试\遮脸工具\`）。
- 准备一个视频文件夹，放 3–5 条片（含至少一条竖屏手机原片、一条多人、一条有转身/低头），文件夹或文件名带中文。

## 逐项测
| # | 做什么 | 看什么 |
|---|---|---|
| 1 | 双击 `遮脸工具.exe` | 是否弹 SmartScreen；点"仍要运行"后窗口能否出现 |
| 2 | 选视频文件夹，点开始 | 进度条是否走动；日志区有无报错 |
| 3 | 处理完点"打开输出文件夹" | 每条视频是否有 4 个文件；`处理日志.txt` 里每条的用时 |
| 4 | 打开 `*_对照图.jpg` | 脸是否被遮住、遮罩有没有跳 |
| 5 | 播放 `*_遮脸.mp4` | 有声音、不卡、时长和原片一致 |
| 6 | 再点一次开始（同一批） | 应全部"跳过"，不覆盖 |
| 7 | 命令行：`facemask-cli.exe --diagnose` | 把输出整段复制下来 |

## 出问题时把这些发回来
- 屏幕上的报错文字或截图；程序旁边的 `遮脸工具_错误.log`（如有）。
- 输出文件夹里的 `处理日志.txt`、`任务清单.json`。
- `facemask-cli.exe --diagnose` 的输出。
- 电脑的 CPU 型号、内存、Windows 版本。
